# 생활체육 수영 강습 AI 맞춤형 수업 지원 시스템

RAG 기반 AI가 반의 수준·특성에 맞는 수업안을 자동으로 짜주는, 수영 강사용 프로토타입입니다. 강사는 반 정보만 등록하면 웜업·메인·쿨다운으로 구성된 초안을 받고, 강사의 피드백과 항목 수정으로 다듬은 뒤 확정합니다.

## 문제의식

수영 강사는 표준화된 커리큘럼 없이 개인 경험과 감에 의존해 수업을 설계합니다. 자체 설문(수영강사 n=12) 결과 강사 절반 이상이 반 수준 편차를 "매우 다양함"으로 답했고, 커리큘럼 가이드를 받아본 적 없는 강사도 절반에 달했습니다. 그 결과 강사별 지도 편차가 커지고, 수강생은 진도를 체감하기 어렵고, 수업 준비는 매번 즉석에서 이뤄집니다.

## 무엇을 만드는가 (1차 프로토타입, ~8/10)

- **반 등록** — 반 정보(수준·나이대·인원·수업 목표 등) + 회원 등록(선택, 최대 10명)
- **수업안 자동 생성** — 장비·강사 요청(자연어)을 받아 AI가 웜업/메인/쿨다운 구조로 초안 생성
- **수업안 확인·수정** — 총 운동량 자동 계산, 항목별(개수×거리) 수정 시 소계·총량 자동 재계산
- **수업 진행·확정** — 루틴별 체크, 수업 종료 처리

리포트 발송, 수강생 웹리포트, 로그인 화면 등은 2차(8/14) 이후 범위입니다.

## 어떻게 동작하는가

1차 프로토타입 기준 수업안 생성은 벡터 검색(RAG)과 조건 조회를 함께 씁니다.

- **드릴(운동 동작) 선택** — `drill_library.json`(라벨링된 드릴 200개)을 레벨·나이대·영법 조건으로 조회합니다. 원본이 이미 영법별로 분류돼 있어 벡터 검색 없이 규칙 기반 조회만으로 충분합니다.
- **이론 자료 검색** — 한글 이론서(대한수영연맹 훈련지도서 등)를 벡터 DB에 임베딩해두고, 코칭 포인트 근거로 검색합니다. 이 부분만 정확히 RAG(Retrieval-Augmented Generation)입니다.
- 두 결과와 서버가 계산한 목표 운동량·시간 배분을 함께 프롬프트에 넣어 LLM이 최종 수업안을 생성합니다.

## 기술 스택

| 영역 | 기술 |
|---|---|
| 프론트엔드 | React Native + TypeScript (`apps/mobile`) |
| 백엔드 | Python FastAPI + Pydantic + SQLAlchemy, API-Service-CRUD 3계층 구조 (`apps/server`) |
| 인프라 | GCP Compute Engine VM (Ubuntu 22.04), Cloud SQL |
| AI / RAG | 시스템 프롬프트 직접 호출 + 조건 기반 드릴 조회 + 벡터 검색(이론 자료) |

## 저장소 구조

```
apps/
├── mobile/   # React Native 프론트엔드
└── server/   # FastAPI 백엔드
```
